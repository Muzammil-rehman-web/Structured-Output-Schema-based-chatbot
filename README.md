# Structured Output with Groq & LangChain 

This project demonstrates how to generate **structured JSON output** from a large language model
using **LangChain's schema enforcement** and **Groq’s LLaMA 3.3 (70B)** model.

Instead of free-form text, the model returns predictable, typed data—ideal for production systems.

---

#  Features

- Uses **Groq LLaMA-3.3-70B-Versatile**
- Enforces output structure using `TypedDict`
- Returns clean, machine-readable JSON
- Secure API key handling with `getpass`
- Compatible with **LangChain v3**

#  Use Case

This approach is useful for:
- Sentiment analysis
- Review summarization
- Data extraction
- API-ready LLM outputs
- AI pipelines & automation

# Tech Stack

- Python
- LangChain
- Groq API
- LLaMA 3.3 (70B)
- TypedDict + Annotated schemas
